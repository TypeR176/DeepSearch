# 前后端分离项目接口文档（图像综合识别\+智能缝合线配方生成V2\.0）

# 1\. 文档概述

## 1\.1 项目简介

本项目基于 FastAPI 开发，采用前后端分离架构、RESTful API 接口规范。全新核心业务流程：前端仅上传一张伤口图片，后端模型完成一站式智能分析，一次性返回全部结果：

1. 识别图片中受伤主体物种（人、猫、狗等）

2. 智能判定伤口损伤等级、伤口创面详细描述

3. 根据物种类型 \+ 伤口严重等级，自动匹配知识库，生成专属适配的医用胶原蛋白缝合线完整配方、原料配比、成分原理分析、生产使用工艺建议。

## 1\.2 基础信息

- 接口根地址：http://IP:8000/api/v1

- 通信协议：HTTP/HTTPS

- 数据交互格式：JSON

- 图片上传格式：multipart/form\-data

- 字符编码：UTF\-8

- 接口在线调试地址：http://IP:8000/docs

## 1\.3 后端技术架构

1. 接口层：FastAPI 路由、图片接收、参数校验、统一数据返回封装

2. 模型层：计算机视觉CV模型（物种识别\+伤口分级）\+ LangChain大模型 \+ RAG专业医学知识库（缝合线配方智能生成）

3. 服务层：图片预处理、多任务联合推理、伤口结果分析、配方动态匹配生成、数据整合

4. 工具层：图片处理、全局异常捕获、跨域配置、接口日志记录

# 2\. 通用接口规范

## 2\.1 统一返回体格式

全接口统一固定返回JSON结构，前端统一解析，无特殊例外格式。

```json
{
    "code": 200,
    "msg": "请求成功",
    "data": {}
}
```

|字段名|类型|说明|
|---|---|---|
|code|int|状态码，200代表成功，非200均为异常|
|msg|string|请求结果提示文案（成功/失败描述）|
|data|object|接口所有业务数据（物种、伤口、配方全部信息）|

## 2\.2 全局状态码定义

|状态码 code|含义|
|---|---|
|200|请求成功，图像识别、配方生成全部完成|
|400|未上传图片、文件参数错误、图片格式不合法|
|404|接口请求地址不存在|
|413|上传图片文件大小超出限制|
|415|图片媒体类型不被服务端支持|
|500|服务器内部异常、图像模型推理、配方生成失败|

## 2\.3 请求头

图片上传专用请求头：

```text
Content-Type: multipart/form-data
```

## 2\.4 图片上传约束

1. 支持图片格式：jpg、jpeg、png

2. 单张图片大小上限：10MB

3. 仅需上传单张图片即可完成全部分析，无需额外传文字参数

4. 后端自动完成图片预处理与模型推理，不返回图片存储链接

# 4\. 整体业务调用流程

1. 前端上传单张伤口图片

2. 前端调用综合接口，以 form\-data 格式上传图片

3. 后端CV视觉模型推理：识别受伤物种、伤口等级、伤情描述

4. 后端依据物种\+伤口等级，调用知识库大模型，动态生成专属缝合线配方

5. 后端整合全部数据，统一返回完整JSON结果

6. 前端解析数据，展示物种信息、伤口等级、伤情描述、原料配比、配方分析、工艺建议

# 5\. 前端对接注意事项

1. 全部业务整合为唯一一个接口，仅需上传一张图片即可完成全部功能，无需多接口分步调用

2. 接口固定使用 multipart/form\-data 上传文件，不可用JSON传输图片

3. 后端已配置全局CORS跨域，前端无需额外处理跨域请求

4. 模型自动区分物种与人宠伤口等级，自动差异化生成专属配方，前端无需额外传入文字需求

5. 建议前端提前校验图片格式、图片大小，减少无效接口请求

6. 所有返回字段结构固定，前端仅需判断code状态码，解析data数据即可页面展示

## 6\.4 伤情分级标准

- 轻度：仅表皮擦伤、浅表破损，创面小，损伤层次浅

- 中度：真皮层受损，创面中等，创口明显，常规缝合即可

- 重度：深层肌肉及组织破损，创面大、伤口深，需要高强度缝合线支撑修复
